科技 / 製造業 · 台中市 · MIS 相關職缺

MIS 資訊管理師
（IT 維運支援）

MIS
學歷要求
大學以上（資管、資工相關科系）
工作經驗
不拘（有實習或專題經驗佳）
薪資待遇
月薪 30,000 ~ 38,000（依能力面議）
工作地點
台中市

職務說明

  • 負責公司內部資訊系統之維護與管理，含 ERP、HRM 等企業應用系統
  • 提供員工電腦設備、網路及軟硬體問題的 IT 支援與故障排除
  • 協助規劃與執行系統導入、更新與升級專案
  • 建立並維護技術文件、使用手冊及 SOP
  • 資訊安全管理，包含帳號權限控管、資料備份與防護措施
  • 協同開發部門進行需求訪談、系統測試與驗收

必備技能

Windows Server 管理 網路設定與排錯 SQL 基礎查詢 技術文件撰寫 溝通協調能力 問題分析與解決 資訊安全觀念

加分條件

Python / VBA 自動化 ERP 使用或導入經驗 資安相關證照 專案管理概念 Linux 基礎操作

我為什麼適合這份工作

🖥
資訊技術底蘊
UCAN 資訊科技應用 4.63 分（PR84），資管課程涵蓋資料庫、網路、OS 管理，具備 MIS 所需技術基礎。
📄
文件與測試能力
技術文件撰寫 4.00、程式測試 4.33，能清楚記錄 SOP、協助驗收測試，確保系統上線品質。
🤝
跨部門溝通協作
人際互動 4.50、團隊合作 4.43，擔任系隊控球後衛的經驗讓我習慣在壓力下協調資源、快速反應。
🛠
系統導入與維護
系統導入 4.00、客戶支援服務 4.50 均為優勢能力，直接對應 MIS 的日常維運工作內容。
📈
責任感與自我要求
工作責任及紀律 4.43，圍棋的覆盤習慣讓我在遇到問題時能系統性地追究根源，而非迴避。
🔍
研究型問題解決
職業性格研究型（I）代表擅長深入分析、追根究柢，遇到複雜的系統問題不輕易放棄，持續尋找解法。
